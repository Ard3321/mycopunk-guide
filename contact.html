Contact Us

Corrections, guide suggestions, and privacy requests — all welcome, all read.

Report an error or suggest a topic

The fastest way to reach us is through the site's GitHub issue tracker. It is public, so other players can confirm the same problem and you can see when it is fixed:

Open an issue on GitHub →

When reporting an error, please include:

  • The page URL (for example /best-weapons.html)
  • What the page says, and what you believe is correct
  • Your game version or patch, if it is a gameplay claim

Guide requests

Want a guide we do not have yet — a specific boss, a farm route, a build? Open an issue with the topic. High-demand requests get prioritized in the weekly update cycle.

Privacy requests

To request access to or deletion of any data we hold about you (in practice: your newsletter email address, if you subscribed), open an issue titled "Privacy request". See the privacy policy for what we collect. We respond within 30 days.

What not to use this for

This site is a fan project and is not affiliated with the developer or publisher of Mycopunk. For account, billing, or technical issues with the game itself, please contact the game's official support channels instead — we cannot help with those.

This site is maintained by one person in spare time. Expect replies within a few days, not minutes — but every message is read.
